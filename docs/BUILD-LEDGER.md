## Sandbox card receipt

One official Unified Checkout card flow now has dated browser proof. The
observed profile used top-level navigation to Hyperswitch's hosted authorization

`stripe_test` attempt, one charged attempt, one successful logical charge, and

submit handler; a browser-native `requestSubmit()` did. This is a known pointer
activation regression to prove in the rebuilt surface, not a reason to change
the Figma design language.
